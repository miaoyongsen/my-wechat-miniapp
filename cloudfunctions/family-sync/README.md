# 家庭资产云同步（两人共享）

1. 在 CloudBase 的云数据库创建集合 `family_assets_private`。权限设为**仅管理员可读写**（禁止小程序客户端直接读写）。
2. 在云函数管理中通过代码包部署**普通云函数** `family-sync`，Node.js 20，自动安装依赖。
3. 在 `family-sync` 的环境变量设置 `FAMILY_SETUP_CODE`，使用至少 12 位的随机口令，**不要提交到 GitHub**。
4. 小程序设置页输入口令，点击「创建家庭云空间」。只有首个成功初始化的微信 OpenID 成为管理员；在云端初始化前必须先设置口令。
5. 管理员生成 10 分钟有效的一次性邀请码，第二个微信账号输入后加入。仅限两个成员。
6. **云端初始化后，首次上传前先在设置页导出 JSON 备份。** 当前本地数据不会自动覆盖云端，用户可选择上传本机资产或从云端下载。
7. 云端采用 revision 乐观锁；同时修改时拒绝覆盖并提示重新同步。未自动合并；冲突时务必先导出本地备份。

安全：云函数根据微信 OpenID 授权，客户端不直连数据库。管理员初始化口令必须配置在云函数环境变量，切勿写入小程序或仓库。行情云函数仍独立。
